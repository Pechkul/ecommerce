## ส่วนที่ 2: การนำเข้าฐานข้อมูล (Database Import)

### การตั้งชื่อฐานข้อมูลและการกำหนดค่าอ้างอิงในไฟล์ .env

ก่อนการสร้างและนำเข้าฐานข้อมูล ต้องตรวจสอบการเชื่อมโยงระหว่างชื่อฐานข้อมูลใน MySQL และไฟล์ตั้งค่า `.env` ดังนี้:

เปิดไฟล์ **`.env`** ในโฟลเดอร์โปรเจกต์ ค้นหาหมวดการตั้งค่าฐานข้อมูล และระบุข้อมูลให้ตรงกับสภาพแวดล้อมเครื่องของคุณ:

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=hatyaibbgun
DB_USERNAME=root
DB_PASSWORD=

```

* **`DB_DATABASE`**: ชื่อฐานข้อมูลที่ต้องการใช้ในระบบ (เช่น `hatyaibbgun`) *ชื่อที่คุณตั้งในบรรทัดนี้ ต้องเป็นชื่อเดียวกันกับฐานข้อมูลที่จะสร้างในขั้นตอนถัดไป*
* **`DB_USERNAME`**: รหัสผู้ใช้ MySQL (หากใช้ Laragon ค่าเริ่มต้นปกติคือ `root`)
* **`DB_PASSWORD`**: รหัสผ่าน MySQL (หากใช้ Laragon ค่าเริ่มต้นปกติจะเว้นว่างไว้)

---

### สร้างฐานข้อมูล (Database) ใหม่

เปิดโปรแกรมจัดการฐานข้อมูล เช่น HeidiSQL, phpMyAdmin, DBeaver หรือสั่งงานผ่าน MySQL CLI แล้วสร้างฐานข้อมูลใหม่ตามชื่อที่ระบุไว้ในค่า **`DB_DATABASE`** ของไฟล์ `.env` (เช่น `hatyaibbgun`) พร้อมกำหนด Collation เป็น **`utf8mb4_unicode_ci`**

---

### นำเข้าไฟล์ SQL เข้าสู่ฐานข้อมูล

เลือกดำเนินการตามเครื่องมือที่สะดวก:

* **ผ่าน Laragon (เปิด HeidiSQL จากปุ่ม Database):**
เปิดโปรแกรม Laragon กดปุ่ม **Database** เพื่อเปิด HeidiSQL เลือกล็อกอินเข้า MySQL จากนั้นคลิกขวาที่รายชื่อฐานข้อมูลด้านซ้าย เลือก **Create new > Database** ตั้งชื่อให้ตรงกับ `DB_DATABASE` ใน `.env` จากนั้นคลิกเลือกฐานข้อมูลนั้น ไปที่เมนู **File (ไฟล์)** -> **Run SQL file... (รันไฟล์ SQL...)** เลือกไฟล์ `.sql` ที่แนบมา แล้วกดสั่งรันจนเสร็จสมบูรณ์
* **ผ่าน Terminal / Command Line:**
เปิด Terminal ใน Laragon หรือ PowerShell แล้วรันคำสั่ง:
```bash
mysql -u root -p hatyaibbgun < path/to/your_database_file.sql

```


* **ผ่าน phpMyAdmin / GUI Tool อื่นๆ:**
เลือกฐานข้อมูล `hatyaibbgun` จากนั้นไปที่แท็บ **Import (นำเข้า)** เลือกไฟล์ `.sql` ที่แนบมาให้ แล้วกด **Go (ดำเนินการ)**

---

### อัปเดตและเคลียร์แคชระบบหลังการ Import

รันคำสั่งใน Terminal บนโฟลเดอร์โปรเจกต์ เพื่อให้ระบบรับรู้โครงสร้างและข้อมูลล่าสุด:

```bash
php artisan config:clear
php artisan cache:clear

```
